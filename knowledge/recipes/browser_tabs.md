- Web pages open in the user's own browser (their saved preference, else the Windows default). Name a browser only when the user did: `open gmail in chrome`.
- Known sites work without a domain: `go to youtube`, `open gmail in dia`. Otherwise use the domain: `go to noesisframeworks.com`.
- Site search by URL beats clicking search boxes: `search youtube for X`, `search amazon for X`, `search wikipedia for X`, `search github for X`.
- After a page opens, the screen description lists the page's links and buttons; click them by their exact text.
- Pages open in a new tab, so the user's current tab is kept.
