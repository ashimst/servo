- `go to <domain>` opens the page in a new tab of the user's own browser (their saved preference, else the
  Windows default). Always give a real domain: `go to mail.google.com`, `go to github.com`.
- To use a particular browser the user named: `open chrome` first, then `go to <domain>`.
- Site search by URL beats clicking search boxes: `go to www.amazon.com/s?k=<words+joined+with+plus>`,
  `go to en.wikipedia.org/wiki/Special:Search?search=<words>`, `go to github.com/search?q=<words>`.
- After a page opens, the screen description lists the page's links and buttons: `click [n]`.
- Tabs: `press ctrl+t` new tab, `press ctrl+w` close tab, `press ctrl+shift+t` reopen the last closed tab,
  `press ctrl+l` address bar.
