title: Write text in Notepad and save it
triggers: [notepad, note, text file, jot, save as, write]

---
Windows 11 Notepad reopens earlier tabs. To write into a clean document:
1. `open notepad`
2. `press ctrl+n` (new tab, so old content isn't mixed in)
3. `type "<the exact text>"` (compose the words yourself; never type a description of the text)
4. To save: `save as <name>.txt on the desktop` (or documents). If a "Replace?" dialog appears, `click Yes` only if the user asked to overwrite.
Done when the window title shows the file name with no leading "*".
For long text (over ~1500 characters) prefer `write "<text>" to file desktop\<name>.txt`, then `open notepad` only if the user wants to see it.
