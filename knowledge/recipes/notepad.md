title: Write text in Notepad and save it
triggers: [notepad, note, text file, jot, save as, write]

---
Windows 11 Notepad reopens earlier tabs. To write into a clean document:
1. `open notepad`
2. `press ctrl+n` (new tab, so old content isn't mixed in)
3. `type "<the exact text>" into [n]` on the "Text editor" document (compose the words yourself; never type a description of the text)
4. To save: `press ctrl+s`; in the Save as dialog `type "C:/Users/<name>/Documents/<file>.txt" into [n]` on the
   "File name" box (the full path), then `press enter`. If a "Replace?" dialog appears, `click [n]` on Yes only if
   the user asked to overwrite.
Done when the window title shows the file name with no leading "*".
For long text (over ~1500 characters) the files agent can `write "<text>" to file C:/Users/<name>/Documents/<file>.txt`.
