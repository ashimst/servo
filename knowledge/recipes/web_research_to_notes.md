title: Look something up on the web or an AI chat site and write it into a note
triggers: [look up, find out, summary, summarize, write it, store, gemini, chatgpt, results, links, response]
---
1. `search the web for <query>`, or for an AI site: `go to gemini.google.com`, then
   `type "<question>" into [n]` on the prompt box and `press enter`.
2. AI answers take time: `wait 8`, then look at the screen next round; if it's still generating, `wait 5` again.
3. Read the facts or links from the screen description yourself (`read text` if they aren't listed).
4. `open notepad`, `press ctrl+n`, `type "<your composed text with the facts or links>" into [n]`.
Never use run command to copy text between apps or to send keystrokes.
