id: windows_settings
title: Open a specific Windows Settings page
triggers: [settings, bluetooth, wi-fi, wifi, display settings, sound settings, windows update, default apps, night light, notifications, time zone]
---
Jump straight to the page instead of clicking through Settings: `open settings <page>`, page one of:
bluetooth, network-wifi, display, sound, nightlight, notifications, windowsupdate, defaultapps,
batterysaver, apps-volume, personalization-background, privacy-microphone, dateandtime, about.
Then work on that page next round using the numbered controls on screen.
- A switch: `turn on [n]` / `turn off [n]` (its state is shown as [on]/[off]).
- A dropdown: `choose "<option exactly as listed>" in [n]`. If the option isn't found, the error lists the
  closest options: pick one of those exactly.
